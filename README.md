# Zabbix Toolbar — releases

Release builds and the update feed for **Zabbix Toolbar**, a macOS menu bar app that monitors Zabbix servers.

- Downloads: see [Releases](https://github.com/alexmontoanelli/zabbix-toolbar-releases/releases).
- Update feed (used by the app via Sparkle): `https://alexmontoanelli.github.io/zabbix-toolbar-releases/appcast.xml`

Builds are signed with Developer ID and notarized by Apple.
